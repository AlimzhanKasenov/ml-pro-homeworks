# HW07 — Web parsing и NLP

Парсинг 200 карточек с учебного сайта Books to Scrape и классификация высокого
рейтинга книги (`rating >= 4`) по названию и описанию.

## Файлы

- `parser.py` — самостоятельный парсер с задержкой 0.3 секунды;
- `data/books.csv` — собранный датасет;
- `hw07_web_parsing_nlp.ipynb` — EDA, TF–IDF, подбор регуляризации и оценка;
- `results/` — метрики и топ-50 коэффициентов.

Запуск: открыть ноутбук и выполнить `Restart Kernel and Run All`. Если CSV уже
существует, повторных запросов к сайту не будет.

Текущий test ROC-AUC равен 0.450. Это ожидаемо: сайт предупреждает, что рейтинги
сгенерированы случайно и не связаны с текстами.
